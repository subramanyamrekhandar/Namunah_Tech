# Namunah Technologies

Enterprise IT and AI services website built with **Next.js** and **Tailwind CSS**.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Responsive, accessible layout patterns

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run start` | Serve production build   |
| `npm run lint`  | Run ESLint               |

## Site map

- `/` — Home
- `/services` — Design, Web, Mobile, Cloud & AI, Agentic AI, Generative AI
- `/work` — Case studies
- `/about` — Company
- `/blog` — Articles
- `/contact` — Contact form
